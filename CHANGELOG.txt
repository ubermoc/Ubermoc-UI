UbermocUI changelog (runs until cleared)

1.0.97
- Game pop-ups (such as the experimental camera question the first time an NPC moves the camera) now come first: while one is open, the NPC window no longer takes A, B, Space, Enter or Escape, and it sits underneath the pop-up.
- The pointer now jumps to a pop-up's main button as soon as it opens, also when the camera is still moving.
- Decline, Goodbye and Escape now close the quest the same way the game's own Decline button does (CloseQuest instead of DeclineQuest).
- For 0.4 seconds after Decline, Goodbye or Escape, the same NPC can no longer open again by itself.
- New debug aid: /run UbermocUIDB.npc.trace=true prints NPC events to chat (turn off with =false).

1.0.98
- Aiming: hold the button to aim a ground spell (Heroic Leap, Blizzard, Death and Decay, traps, sigils and more) and release to cast it where the pointer is. The game's own Press and Hold Casting only does anything on release for empowered spells, so the action buttons holding a ground spell now get a release cast of their own (set up out of combat, refreshed whenever the bars change).
- Add a ground spell that is missing with /ubground add Spell Name (/ubground remove Spell Name, /ubground list).
- The aiming mark now also shows while a ground spell's button is held, not only while the game is waiting for a spot.
- The aiming mark has two shapes, Dot and Cross (Both is gone). New default look: white cross, 4 px, 1 px thick, 80% opacity. The old look is replaced once; its place is kept.
- A note under the mark explains that the spell lands where the mouse pointer is, so the pointer must be under the mark.

1.0.99
- Transmog NPC: the pointer now opens when the transmog window opens. The game loads that window and shows it in one step the first time, before the pointer could hook it, so it was missed. The pointer now also starts from the game's own "NPC window opened" event, and hooks a window that is already open.

1.0.100
- Added X-Curse-Project-ID (1745809) to the addon file so CurseForge recognises the project.

1.0.101
- Aiming mark: it now sits where the game keeps the centered pointer while the controller steers the camera (the game's CursorCenteredYPos setting), so it lines up with where a ground spell lands. Left / right and Up / down move it from there.
- New choice "Show it": While aiming, or Always (whenever the controller steers the camera). Always lets you check the mark is drawn at all.
- New command /ubaim: prints what the mark sees (is the game waiting for a spot, is a ground button held, is the controller camera on, how many buttons are set up for hold-and-release) and shows the mark for 3 seconds.

1.0.102
- Aiming: the built-in ground spell list is now only the spells with a source (Heroic Leap, Blizzard, Rain of Fire, Death and Decay), matched by name. The rest of the earlier list (traps, sigils, totems and others) is gone, because a spell that is placed at your feet would have been cast twice. Add any other ground spell with /ubground add Spell Name, using the name your game shows. Spells swapped by a talent or form are recognised through the spell they replace.
- Aiming: new option "Keep the aim in the middle of the screen while aiming a ground spell" (on by default). The game normally hands the aim to the sticks while a ground spell waits (its GamePadCursorForTargeting setting); with this on, that setting is switched off, so the spell lands where the pointer rests in the middle, where the mark is. Your old value is put back when you turn the option off.
- Aiming mark "Always" now shows only while the controller steers the camera with the pointer hidden, not while the game shows its own centered pointer.
- /ubaim also prints the game's GamePadCursorForTargeting value.

1.0.103
- Text only: the notes in the settings and the debug text no longer mention other addons or libraries by name.
